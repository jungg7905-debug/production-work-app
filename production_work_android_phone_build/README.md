# 생산 작업 관리 안드로이드 앱

휴대폰에서 GitHub 저장소를 생성하고 이 프로젝트 파일을 저장소 최상위에 업로드한 뒤 Actions → Build Android APK → Run workflow를 실행하세요. 완료되면 workflow의 Artifacts에서 production-work-apk를 내려받아 압축을 풀고 app-debug.apk를 설치할 수 있습니다.

Android 8.0 이상. 첫 실행 후 알림과 정확한 알람 권한을 허용해야 합니다. 제조사 절전 설정과 강제 종료에 따라 알람이 지연되거나 중지될 수 있습니다. 브라우저의 기존 저장 데이터는 앱으로 자동 이전되지 않습니다.

이 프로젝트는 실제 빌드/기기 테스트 전입니다.
